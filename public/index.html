Protected

What RouteX is

A web gateway for HTTP/HTTPS requests. It is not a device-level VPN and does not tunnel arbitrary mobile-app traffic.

Privacy note

RouteX does not intentionally persist URLs, page content, cookies, or browsing history. Cloudflare may still process operational/security data under its own policies.
